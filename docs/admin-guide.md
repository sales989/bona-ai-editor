# 管理员操作手册

## 管理后台入口
登录后点击右上角「管理后台」进入，或直接访问 `https://v.bona6.com/#/admin`

## 数据概览
展示平台运营数据：
- 总用户数
- 总任务数
- 成功/失败任务数

## 用户管理

### 创建用户
1. 点击「+ 新增用户」
2. 输入用户名和密码
3. 选择角色（普通用户/管理员）
4. 点击创建

### 管理用户
- **禁用/启用**：临时停用账号而不删除
- **改密**：重置用户密码
- **删除**：永久删除用户（不可恢复）

### 权限说明
- **普通用户**：仅能上传、编辑、查看自己的任务
- **管理员**：全量权限，可管理所有用户和任务

## API配置

### 配置AI模型API
1. 在管理后台点击「API配置」
2. 找到对应服务商（PicWish / 通义万相）
3. 点击「配置密钥」
4. 填入API Key并保存

### 模型匹配规则
| 编辑类型 | 使用的模型 | 是否需要配置 |
|---------|-----------|------------|
| 通用编辑（风格/背景/扩图等） | Cloudflare Flux-2-dev | ❌ 无需配置，原生内置 |
| 去水印/文字/杂物 | PicWish消除API | ✅ 需配置API Key |
| 人脸替换/证件照换底色 | 阿里通义万相 | ✅ 需配置API Key |

### 获取API Key
- **PicWish**: https://picwish.com → 注册 → 获取API Key
- **阿里云通义万相**: https://dashscope.aliyun.com → 注册 → 创建API Key

## 安全建议
1. 首次登录后立即修改初始密码
2. 定期清理不再使用的账号
3. API Key定期更换
4. 不要将登录信息分享给非授权人员
